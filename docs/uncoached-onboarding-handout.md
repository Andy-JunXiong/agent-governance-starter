# AgentGov uncoached onboarding task

You have been given:

- the AgentGov repository:
  `https://github.com/Andy-JunXiong/agent-governance-starter`;
- a local test-repository path;
- an AgentGov commit selected by the facilitator.

Complete the task without asking the facilitator how to run a command or
interpret a finding. You may use repository documentation and command help.
If you become blocked, say what you expected to find and where you looked.

## Goal

Install the reviewed AgentGov commit in an isolated tool environment, inspect
the test repository without writing, review the complete onboarding plan,
decide whether to authorize it, identify the next action, and create a
repository governance report.

## Safety rules

- Confirm the target path before any write.
- Run a dry-run before authorizing onboarding.
- Do not edit or delete pre-existing target files.
- Do not stage, commit, push, merge, publish, release, or deploy.
- Do not hide WARN, FAIL, or ADVISORY findings.
- Stop if the target contains sensitive or unexpected data.

## Completion evidence

Before you finish, show the facilitator:

- the installation command you selected;
- the `doctor` result;
- the dry-run plan and evidence that it wrote nothing;
- the exact confirmation decision you made;
- the automatic first repository-check summary;
- the single action selected by `next`;
- the generated Markdown or JSON repository report.

Then answer:

1. What did dry-run authorize?
2. What additional authority did exact `ADOPT` grant?
3. Does generated scaffolding mean governance is complete?
4. How do PASS, WARN, FAIL, and ADVISORY differ?
5. Can AgentGov authorize merge, release, or deployment?
6. What is the next accountable action for this test repository?

The task is complete when the report exists and you have answered all six
questions.

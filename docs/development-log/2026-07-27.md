# Agent Governance Starter Kit Development Log — 2026-07-27

## Outcome

AgentGov recorded a rejection-by-default boundary for proposed governance
semantic relations without adding a schema, checker, CLI command, report
field, or migration.

ADR-0006 treats the existing Inventory, Capability, Control Mapping,
Dependencies, Evaluation, Artifact, and report contracts as the authoritative
implicit semantic model. A candidate relation must begin with an observed
cross-domain gap and must survive an existing-contract-first remedy review.

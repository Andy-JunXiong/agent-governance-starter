# Active Task guided-first Monitor v1 - 2026-09-02

## Goal, non-goals, acceptance, and stop

The goal is to make the existing self-contained Development Monitor HTML a
practical first-time task-review surface. A concise six-dimension explanation
and Active Task become primary, while the complete historical Monitor remains
available through script-free progressive disclosure.

The slice does not change the strict 1.10 JSON contract, Markdown semantics,
event or scope-evidence contracts, governance-state derivation, or authority
boundary. It does not add a separate page or mode, remove historical content,
run a participant study, or authorize Git, publication, release, or deployment.

Acceptance requires preserved evidence and internal navigation, a
default-closed full-history disclosure, responsive and keyboard-accessible
native HTML, explicit assisted-versus-uncoached labeling, and passing focused
and complete validation. Stop if the disclosure hides evidence, breaks Task
Detail navigation, requires script, changes schema semantics, or absorbs any
pre-existing excluded path.

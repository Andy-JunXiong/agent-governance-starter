## Verified-session handoff and rollover contract

- ADR-0012 rejects deleting `.agentgov/current-task.json`: deletion loses the
  exact session identity and would make a lone completed admitted task
  automatically discoverable again.

  `session.handed_off: handed_off` event after re-establishing the exact active

  cancelled, non-interactive, stale, drifted, and duplicate paths write

- Automatic discovery must exclude the same handed-off task digest, retain
  explicit choice among multiple tasks, and treat a changed digest only through
  normal reviewed start.
- Monitor remains a derived read model. Future support may display handoff
  separately from completion and print the handoff preview as guidance, but it

## Automatic product experience and Dashboard direction

The human product owner clarified that the implemented manual lifecycle is not
the intended user experience. AgentGov must behave like an automatic software
product around the coding agent: the user requests work naturally, confirms
only real scope or authority boundaries, and reviews the result while AgentGov
automatically coordinates context, scope observation, approved validation,
fresh evidence, Monitor, and Dashboard updates.

- Added ADR-0013 and the canonical automatic-governance product requirements.
- Reclassified `next`, `govern start/check/finish`, Monitor generation, and
  handoff as internal, headless, CI, diagnostic, testing, and recovery
  primitives rather than the final daily journey.
- Made an explicit foreground coordinator and vendor-neutral adapter contract
  the next general product slice; a hidden daemon, automatic local-state
  upload, and host configuration as governance authority remain out of scope.
- Made the automatically refreshed Dashboard a core product surface with
  Overview, Live Sessions, Protection Events, Task Detail, Benefit, and
  Learning views.
- Defined benefit evidence as observed fact, reproduced comparison with a
  denominator and applicability model, supported inference, attributed human
  feedback, or unknown. No combined governance, protection, ROI, or benefit
  score was admitted.
- Required the automatic experience to protect both the user and coding agent
  by bounding authority and responsibility, surfacing stale evidence and
  repeated work, and keeping semantic judgment human-owned.
- Moved the NYC shadow pilot behind an independent non-NYC automatic-journey
  rehearsal. NYC remains the first real consumer feedback source, not an
  AgentGov implementation source; consumer-specific paths, policy, data,

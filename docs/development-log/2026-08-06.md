- Added strict `agentgov.coding-agent-event` 1.0 input. It accepts only event
  identity, time, event type, adapter/actor identity, correlation identity, and

  and completion decisions.

  identity, and authority flags from the host contract.

  stdin in one disclosed foreground process and flushes one

  validation remains advisory context rather than completion evidence.

  events return a bounded task card. Completion requests return a completion
  card derived from AgentGov scope, pre-approved validation, and reconciliation
  outcomes.
- Card actions are offers to the host or human. They grant no scope expansion,
  exception, commit, merge, release, publication, or deployment authority.
- Preserved the existing single-cycle `agentgov dev --event ...` surface and
  low-level headless fallbacks.

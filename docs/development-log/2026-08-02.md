# Agent Governance Starter Kit Development Log — 2026-08-02

## Outcome

Release-candidate evidence collection no longer requires a maintainer to run
and reconcile a manual list of AgentGov and NYC commands. The new
`agentgov review release` command creates one local, portable review bundle
while preserving the final approve, request-changes, or reject decision for a
human.

## Work completed

  SHA-256 matching before any evidence collection.
- Added isolated installation of the exact candidate wheel without consumer
  project dependencies.
- Automated the complete source tests, installed version and manifest checks,
  consumer repository check, Markdown status rendering, and upgrade-policy
  plan.
- Added atomic create-new-only bundle output. Existing paths and symbolic-link
  inputs are never overwritten or followed.
- Added portable `review.json`, human-readable `REVIEW.md`, raw command
  transcripts, the reviewed manifest, and the exact candidate wheel.
- Added a strict release-review schema with an all-false Git, publication,
  release, and deployment authority boundary.
- Added consumer-local stable upgrade review with portable JSON, Markdown UI,
  an exact workflow patch, current project status, four deterministic gates,
  and a pending project-owner decision.
- Added explicit release-candidate blocking and an authority contract that
  distinguishes evidence output from governed-file or Git modification.
- Extended only the 0.2+ managed consumer workflow to download the latest
  stable manifest once, generate the consumer upgrade review, append its UI to
  the GitHub job summary, and upload the complete evidence directory.
- Preserved the published stable 0.1 workflow byte-for-byte and retained
  read-only GitHub permissions with no PR writer.

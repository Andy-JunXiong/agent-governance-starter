# v0.1 clean-repository adoption rehearsal

## Purpose

This rehearsal verifies that a project can install the packaged CLI and follow
the complete starter workflow without importing the Agent Governance Starter
Kit source tree or any AI Radar code, data, or configuration.

It validates package wiring and deterministic policy behavior. It does not
claim that a newly initialized project's governance decisions or model quality
are complete.

## Rehearsal contract

Date: 2026-07-13

Environment:

- Windows PowerShell;
- Python 3.12.10;
- `agent_governance_starter-0.1.0.dev0-py3-none-any.whl`;
- isolated build and runtime virtual environments;
- a new temporary target directory.

The build environment installed `setuptools`, `wheel`, and their packaging
dependency. The runtime environment installed only the generated starter-kit
wheel with `--no-deps`.

## Installed workflow

The installed `agentgov` executable completed these steps in order:

1. initialize a new repository scaffold;
2. validate the example capability manifest;
3. validate its repository-local references;
4. check the example evaluation bundle;
5. validate the installed agent operating protocols;
6. export the example capability artifact;
7. verify the exported artifact;
8. check the complete initialized repository;
9. write a Markdown governance report.

The exact user-facing command sequence is maintained in the root README.

## Expected open work after initialization

The final three warnings are intentionally non-blocking:

- the generated governance documents still contain human-review placeholders;
- the example capability has no evaluation evidence yet;
- the evaluation bundle honestly declares `needs_seed_cases`.

The repository also emits one advisory reminder for human governance review.
These findings must remain visible until project-specific owners supply real
decisions and evidence.

## Automated regression coverage

`tests/test_adoption_path.py` exercises the same CLI sequence against a fresh
temporary repository. It asserts that all commands return the non-blocking exit
code, the final counts remain explicit, expected warnings remain visible, and
the report contains no unsupported governance percentage.

## Scope limitations

- Package publication to an external index was not attempted.
- No Git repository, commit, push, pull request, or release was created.
- No claim is made about Linux or macOS packaging in this rehearsal.
- No human ten-minute adoption claim is established until a person completes
  placeholder review and records the result separately.

Troubleshooting

Identify whether the problem is installation, repository state, a deterministic failure, or a decision that automation cannot make.

agentgov is not found

The pipx scripts directory may not be on PATH. Install the published stable wheel, expose the pipx command path, and open a new terminal if needed.

python --version
pipx install "https://github.com/Andy-JunXiong/agent-governance-starter/releases/download/v0.2.1/agent_governance_starter-0.2.1-py3-none-any.whl"
pipx ensurepath
agentgov --help

Windows wheel build fails with No such file or directory

A starter clone nested inside a deeply located target repository can exceed the effective Windows build path limit. Return to the target repository root and install the published wheel through pipx.

Set-Location ..
pipx install "https://github.com/Andy-JunXiong/agent-governance-starter/releases/download/v0.2.1/agent_governance_starter-0.2.1-py3-none-any.whl"
agentgov --help

Do not commit the nested starter clone. Confirm its exact path and contents before removing it.

The virtual environment points to a missing Python

The environment is stale. Check the repository's declared Python version and dependency files before recreating it. A successful CLI run through another system Python does not prove the project's test environment works.

check says invalid choice: '.'

The check target must come before the path. Formatting options belong to report, not check.

agentgov check repository .

adopt reports CONFLICT

Do not force the write. Inspect the named path and determine whether it is a directory, ordinary file, or symbolic link.

agentgov inspect path/to/repository

CONFLICT docs/adr — expected directory, found file

Rename or deliberately migrate the conflicting path, rerun inspect, and only then preview adoption again.

WARN remains after adoption

WARN is not necessarily a bug. It means a valid state is honestly incomplete.

governance:placeholdersReplace the placeholder or record an owner and explicit deferral.
evaluation:needs_seed_casesAdd reviewed cases, or keep the warning until evidence exists.
artifacts:directoryExport reviewed capability artifacts when the project is ready to track drift.

FAIL appears

FAIL means a deterministic contract is violated. Correct the named file or reference; do not weaken the checker or delete its test.

FAIL references:refund-reply:contracts
Finding: output schema path does not exist
Next: correct the manifest path or restore the schema

ADVISORY cannot be “fixed”

ADVISORY marks a judgment outside static analysis. For example, the CLI can confirm that a human-review stage is declared, but cannot decide whether it is adequate for the repository's real refund risk.

Record the accountable person, decision, rationale, and follow-up in an ADR or equivalent repository-owned record.

The HTML report looks stale

The report is a static snapshot. Regenerate it after repository facts change. Output refuses to overwrite an existing file, so choose a new path or deliberately remove the old generated report first.

agentgov report repository . --format html --output governance-report-new.html

Escalate when

  1. The correct authority relationship is unclear.
  2. A proposed fix changes approval or deployment boundaries.
  3. Evidence contains private or production-derived data that is not sanitized.
  4. A warning would be hidden instead of honestly resolved or deferred.

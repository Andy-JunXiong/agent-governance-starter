修改前先诊断

故障排查

先判断问题属于安装、仓库状态、确定性失败，还是自动化无法作出的决定。

重新加载后仍然缺少工具（开发源）

当前开发源提供一个只读、仅限开发源的本地 MCP 配置预览，用于选定的仓库：

$env:PYTHONPATH = "src"
python -m agentgov doctor . --format json --non-interactive

它只读取 .codex/config.toml，分别报告基础工具和表单门控工具，先应用可选的 enabled_tools 再应用 disabled_tools，并将显式 tool_timeout_sec 与 AgentGov 生成配置建议的 1800 秒比较。省略的超时、合并后的主机配置、信任状态、加载版本、实时激活和表单能力都保持未知；文档中的主机默认 60 秒不等于实际生效值。

结果只提供非阻塞的 PASS、WARN 或 ADVISORY 指引。预览不会自动启用或修复配置、连接实时服务器，也不会回显密钥、未知名称、解析错误或配置中的命令、环境值。符号链接/重解析点、非普通文件、超过 256 KiB、不可读或格式错误的文件会产生规范化警告；缺少本地集成则标记为不适用。这是开发源行为，不表示稳定版 0.2.1 或已发布的 0.3.0rc1 包含它。详细诊断契约见MCP 适配器指南。

找不到 agentgov

通常是 pipx 的脚本目录不在 PATH 中。请安装已发布的稳定版、公开 pipx 命令路径，并在需要时重新打开终端。

python --version
pipx install "https://github.com/Andy-JunXiong/agent-governance-starter/releases/download/v0.2.1/agent_governance_starter-0.2.1-py3-none-any.whl"
pipx ensurepath
agentgov --help

Windows 构建 wheel 时出现 No such file or directory

如果把 starter 克隆在路径已经很深的目标仓库内部，pip 的临时构建路径可能超过 Windows 的有效路径限制。请返回目标仓库根目录，通过 pipx 安装已发布 wheel。

Set-Location ..
pipx install "https://github.com/Andy-JunXiong/agent-governance-starter/releases/download/v0.2.1/agent_governance_starter-0.2.1-py3-none-any.whl"
agentgov --help

不要提交嵌套的 starter clone。删除前必须确认准确路径，并确认其中没有需要保留的工作。

虚拟环境指向不存在的 Python

这说明环境已经失效。重建前先核对仓库声明的 Python 版本和依赖文件。用另一个系统 Python 成功运行 CLI，不能证明项目测试环境有效。

check 报告 invalid choice: '.'

必须先写检查类型，再写路径；格式选项属于 report，不属于 check。

agentgov check repository .

adopt 报告 CONFLICT

不要强制写入。检查报告中的路径，确认它是目录、普通文件还是符号链接。

agentgov inspect path/to/repository

CONFLICT docs/adr — 预期为目录，但发现普通文件

重命名或有计划地迁移冲突路径，重新运行 inspect，然后再次预览接入。

接入后仍然存在 WARN

WARN 不一定是程序错误。它表示一个有效状态被如实标记为尚未完成。

governance:placeholders替换占位符，或记录负责人和明确延期。
evaluation:needs_seed_cases添加已审阅案例；证据尚不存在时保留警告。
artifacts:directory项目准备跟踪漂移后，再导出已审阅能力制品。

出现 FAIL

FAIL 表示确定性契约被违反。修正报告指出的文件或引用；不要削弱检查器或删除测试。

FAIL references:refund-reply:contracts
发现：输出 Schema 路径不存在
下一步：修正清单路径或恢复 Schema

ADVISORY 不能被自动“修复”

ADVISORY 表示静态分析范围之外的判断。例如，CLI 可以确认已经声明人工审阅阶段，却不能决定该阶段是否足以应对仓库真实的退款风险。

请在 ADR 或其他仓库自有记录中写明责任人、决定、理由和后续工作。

HTML 报告看起来过时

报告是静态快照。仓库事实变化后需要重新生成。输出命令拒绝覆盖已有文件，因此请选择新路径，或在确认后处理旧的生成报告。

agentgov report repository . --format html --output governance-report-new.html

以下情况需要升级给人处理

  1. 无法确定正确的指令权威关系。
  2. 修复方案会改变审批或部署边界。
  3. 证据包含尚未脱敏的私有数据或生产衍生数据。
  4. 有人试图隐藏警告，而不是如实解决或延期。

10 分钟接入路径

快速入门

先检查，再预览每次写入，只创建缺失的治理文件，最后审阅自动化无法决定的事项。

开始之前

在需要治理的仓库根目录打开终端，并激活该仓库自己的 Python 环境。使用 Python 3.11 或更新版本。静态检查通过只表示声明的确定性契约成功执行；它不授权合并、发布或部署。

1. 安装

请从需要治理的仓库运行以下命令。它们会把当前开发版本安装到已激活的 Python 环境，而不会把 starter 源码复制进被治理仓库。

python --version
python -m pip install "git+https://github.com/Andy-JunXiong/agent-governance-starter.git@main"
python -m agentgov --help

不安装直接运行

如果要开发 starter kit，请把它克隆到独立且较短的路径，再从包含 src 目录的 clone 根目录运行以下其中一种命令。不要把 starter clone 到被治理仓库内部。

PowerShell
$env:PYTHONPATH = "src"
python -m agentgov --help
Bash / zsh
PYTHONPATH=src python -m agentgov --help

2. 接入已有仓库

如果终端已经位于目标仓库根目录，请使用 .。每次只运行一条命令，确认输出后再继续。

python -m agentgov inspect .
python -m agentgov adopt . --project-name "My Project" --dry-run
python -m agentgov adopt . --project-name "My Project"
python -m agentgov check repository .
PRESENT保留并审阅现有治理路径。
MISSING决定接入计划是否应创建它。
DISCOVERED人工审阅其他工具的仓库指令。
CONFLICT先解决路径类型或符号链接冲突。

CLI 不覆盖普通文件，不合并 CLAUDE.md 或厂商指令，也不运行 Git 命令。

首次检查的正常结果：刚接入的仓库可能同时出现 PASS、WARN 和 ADVISORY。占位符、draft seed cases、尚未配置的 artifacts 和人工审批边界仍需按项目实际情况审阅。FAIL=0 不代表接入已经完成。

3. 创建新仓库

PowerShell
$Project = Join-Path $PWD "governed-project"
python -m agentgov init $Project --project-name "My Project"
python -m agentgov check repository $Project
Bash / zsh
PROJECT="$PWD/governed-project"
python -m agentgov init "$PROJECT" --project-name "My Project"
python -m agentgov check repository "$PROJECT"

4. 检查并生成报告

PowerShell
python -m agentgov check repository path/to/project
python -m agentgov report repository path/to/project `
  --format html `
  --output path/to/project/governance-report.html
Bash / zsh
python -m agentgov check repository path/to/project
python -m agentgov report repository path/to/project \
  --format html \
  --output path/to/project/governance-report.html

5. 仍需完成的人工工作

  1. 替换占位符，或明确记录延期。
  2. 解决各指令文件之间的权威关系。
  3. 声明真实的能力归属、风险和人工审阅阶段。
  4. 添加经过审阅的评估证据。
  5. 为 ADVISORY 发现记录可追责的决定。

继续阅读

已有仓库接入指南 安全检查、预演并接入现有项目。 生成文件填写指南 理解并填写各项治理文件。 故障排查 处理安装、冲突、WARN 和 ADVISORY。 查看示例报告 了解检查结果和人工审阅边界。

Guided refund example

A coding agent changed too much. What happens next?

A small bug fix passes its tests, but the agent also changes a rule nobody asked it to touch.

3–4 minutes Six steps · one observable scenario · optional technical follow-up
Human request Fix the refund calculation bug.
Allowed for this task refunds/calculation.py
Separate decision refunds/approval_policy.py

  1. Boundary
  2. Extra change

01

The person sets the boundary.

Fix the refund calculation. Changing the approval rule would be a separate decision.

ALLOWED
Person

Defines the task and allows one file.

Coding agent

Works on the requested change.

AgentGov

Checks the changed files against that boundary.

Demo script

Replays the example so the same sequence can be shown again.

02

The agent fixes the bug—and one thing it was not asked to.

The calculation fix is correct. But the agent also raises the human approval limit from 100 to 500.

SIMULATED AGENT
refunds/calculation.pyIN SCOPE
- return subtotal
+ return subtotal - eligible_refund

# requested calculation repair
refunds/approval_policy.pyOUT OF SCOPE
- HUMAN_APPROVAL_LIMIT = 100
+ HUMAN_APPROVAL_LIMIT = 500

# nobody asked for this change
03

AgentGov catches the extra change.

One changed file is allowed for this task. One is not.

BLOCKED
PASS · allowed file

refunds/calculation.py matches the task.

FAIL · extra file

refunds/approval_policy.py was not approved for this task.

Completion: BLOCKED

The work is not automatically undone. It simply cannot be called complete in its current form.

04

A person decides what happens next.

There is a real choice: expand the task, or remove the extra change.

HUMAN DECISION
Expand the task

Review the approval-rule change as a separate piece of work.

Remove the extra change

Selected. The approval rule is not part of this task.

05

The out-of-scope change is reverted.

For reproducibility, the demo script restores approval_policy.py to its original value.

DEMO SCRIPT
Keep the requested fixThe refund calculation remains changed.
Restore the approval ruleThe limit goes back from 500 to 100.
Run the checks againThe current files are checked, not an earlier result.
06

Ready for review—not accepted.

The extra change is gone. The requested fix and its tests now pass the current checks.

# AgentGov 0.2.0

Status: local stable-release source and review evidence are prepared; not
committed, tagged, published, or deployed.

## Purpose

AgentGov 0.2.0 makes repository governance visible in consumer CI and prepares
safe, human-controlled upgrades without granting branch, pull-request, merge,
release, or deployment authority.

## Added

- Read-only `agentgov status` views for terminals, JSON consumers, and GitHub
  job summaries.
- Create-missing-only `agentgov integrate github-actions` for pinned,
  read-only consumer governance CI.
- Weekday scheduled stable-update discovery in 0.2 managed consumer workflows,
  in addition to push, pull-request, and manual triggers.
- Read-only upgrade planning and consumer-local upgrade review bundles with an
  exact managed-workflow patch and pending project-owner decision.
- Before/after governance report comparison with explicit denominators and no
  causal, coverage, time-saving, or ROI claims.
- Release review bundles that exercise an exact wheel, immutable manifest,
  source tests, and a selected consumer pilot.
- Separate automated GitHub workflows for release candidates and stable
  releases.

## Compatibility

- Supported source tool version: `0.1.0`.
- Readable and target repository layout: `1.0`.
- Repository migrations: none.
- Existing reviewed 0.1 consumer workflows remain recognizable and eligible
  for an exact managed upgrade.

# AgentGov 0.2.1

Status: local patch source and tests are prepared; not yet tagged or published.

## Purpose

AgentGov 0.2.1 corrects the managed consumer workflow after the first NYC
GitHub Actions run showed that pip rejects a valid wheel downloaded under the
non-canonical filename `agentgov.whl`.

## Fixed

- Preserve `agent_governance_starter-<version>-py3-none-any.whl` as the local
  download filename before digest verification and installation.
- Add a workflow regression test that forbids the invalid temporary filename.
- Preserve `0.1.0` and `0.2.0` as compatible upgrade sources in the generated
  stable manifest.
- Generate stable manifests from the bundled compatibility metadata so patch
  upgrade support is not lost during publication.

## Boundaries

- No repository layout migration is declared.
- The workflow retains read-only repository permissions.
- AgentGov does not authorize merge, release, deployment, or production work.
- NYC business code and production workflows are outside this patch.

## Evidence required before publication

- Complete source and installed-wheel tests pass. Local review passed 374 tests
  with one platform-limited skip.
- Six Ubuntu/Windows and Python 3.11/3.12/3.13 CI jobs pass.
- The local stable wheel and strict manifest match SHA-256
  `970e36e13ae6cf9df54cf744fb26e940e9a4181b3df210942ee1d8bc048e446e`.
- The local AgentGov/NYC release review passed all seven gates, and the NYC

- After publication, repeat the NYC review from the public manifest and require

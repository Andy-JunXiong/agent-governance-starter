10-minute adoption path

Quickstart

Inspect first, preview every write, create only missing governance files, then review what automation cannot decide.

Before you start

Use Python 3.11 or newer from a source checkout. A passing static check means a declared deterministic contract ran successfully; it does not authorize merge, release or deployment.

1. Install

The package currently declares zero runtime dependencies.

python -m pip install .
agentgov --help

Run without installing

PowerShell
$env:PYTHONPATH = "src"
python -m agentgov --help
Bash / zsh
PYTHONPATH=src python -m agentgov --help

2. Adopt an existing repository

agentgov inspect path/to/project
agentgov adopt path/to/project --project-name "My Project" --dry-run
agentgov adopt path/to/project --project-name "My Project"
PRESENTPreserve and review the existing governance path.
MISSINGDecide whether the adoption plan should create it.
DISCOVEREDReview another tool's repository instructions manually.
CONFLICTResolve the path type or symbolic-link conflict first.

The CLI does not overwrite regular files, merge CLAUDE.md or vendor instructions, or run Git commands.

3. Start a new repository

PowerShell
$Project = Join-Path $PWD "governed-project"
agentgov init $Project --project-name "My Project"
agentgov check repository $Project
Bash / zsh
PROJECT="$PWD/governed-project"
agentgov init "$PROJECT" --project-name "My Project"
agentgov check repository "$PROJECT"

4. Check and generate a report

PowerShell
agentgov check repository path/to/project
agentgov report repository path/to/project `
  --format html `
  --output path/to/project/governance-report.html
Bash / zsh
agentgov check repository path/to/project
agentgov report repository path/to/project \
  --format html \
  --output path/to/project/governance-report.html

5. Human work still required

  1. Replace or explicitly defer placeholders.
  2. Resolve authority relationships among instruction files.
  3. Declare real capability ownership, risk and human-review stages.
  4. Add reviewed evaluation evidence.
  5. Record accountable decisions for ADVISORY findings.

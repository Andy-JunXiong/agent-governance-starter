# Evidence Freshness rehearsal site

This standalone Sites project publishes the bounded Chinese rehearsal page as
an unlisted test link. The participant-facing file is
`public/rehearsal.html`; the root route redirects to it.

The page keeps answers in browser memory and contains no submission endpoint,
analytics, persistence, account, answer key, score, or automatic pass/fail
behavior. Its production URL is test publication, not formal product release
or adoption evidence.
